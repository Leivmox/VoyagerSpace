# 远航星际 (Voyager Space) 官网设计

## 1. 项目简介
本项目设计了“远航星际”太空旅游公司的官方网站。
**定位：** 高端商业太空旅行服务商。
**Slogan：** 跨越光年，触手可及。

## 2. 项目亮点
1. **视觉风格：** 采用深空蓝与霓虹青配色，营造沉浸式科幻氛围。
2. **交互设计：** 实现了二级下拉导航、产品卡片悬停3D浮动效果。
3. **功能模块：** 包含航班时刻表（表格）、登船验证（JS表单验证）及全屏轮播图展示。

## 3. 技术栈
HTML5 / CSS3 (Flex, Position, Animation) / 原生 JavaScript
